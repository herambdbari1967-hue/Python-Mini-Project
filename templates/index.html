Python Mini Project

Movie Ticket Price & Show Finder Automation

This application automates the comparison of movie show timings, theatre listings, and seat tier prices across different cinema multiplexes.

Key Technologies Used:

  • Python Flask: Backend REST API & application server
  • Pandas: Data structuring, aggregation, and CSV export engine
  • Schedule & Threading: Background price watcher and alert notifier
  • Vanilla CSS & JS: Custom OnePlus design system with dynamic live filters
  • 1-Click Booking: Smart booking URL generator for instant ticketing
